# Machine Learning Lab Practicals

## 📌 About This Repository

This repository contains my **Machine Learning Lab practical programs** implemented using Python in Jupyter Notebook.

The main purpose of this repository is to understand and implement different Machine Learning algorithms through practical experiments.

I have used different datasets to execute algorithms, understand their working, and observe their results.

## 🧠 Practical Programs

The following Machine Learning algorithms are implemented in separate Jupyter Notebook files.

| No. | Algorithm | Notebook |
|---|---|---|
| 1 | Decision Tree | `decision_tree.ipynb` |
| 2 | K-Means Clustering | `K_Means.ipynb` |
| 3 | K-Nearest Neighbour | `K_Nearest_Neighbour.ipynb` |
| 4 | Linear Regression | `linear_regression.ipynb` |
| 5 | Linear Regression Lab 2 | `Linear Regression Lab2.ipynb` |
| 6 | Naive Bayes | `Naive_Bayes.ipynb` |
| 7 | Perceptron | `Perceptron.ipynb` |
| 8 | Random Forest | `Random_Forest.ipynb` |
| 9 | Support Vector Machine | `SVM.ipynb` |

## 📊 Datasets

The following datasets are included in this repository:

- **Salary_Data.csv** – Dataset used for salary-related prediction experiments.
- **diabetes_prediction_dataset.csv** – Dataset used for diabetes prediction experiments.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Platform:** Jupyter Notebook
- **Libraries:**
  - Pandas
  - NumPy
  - Matplotlib
  - Scikit-learn

## ⚙️ Requirements

Install Python and Jupyter Notebook on your system.

Install the required libraries using:

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Launch Jupyter Notebook.
4. Open any `.ipynb` file.
5. Execute the code cells one by one.
6. Observe the output and results.
